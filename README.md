# Java

Java coursework and practice projects, grouped by course. The strongest project is the [GFT REST API](gft/desafio-api), a Spring Boot service using JPA, Hibernate, and Spring Security. Its Angular client lives in [typescript/gft/desafio-angular](https://github.com/LucasPedrosoTI/typescript/tree/main/gft/desafio-angular).
